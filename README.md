# 매일 불어 테스트 🇨🇮

아비장에서 불어를 배우는 한국인을 위한 하루 루틴 앱.

- 저녁: 오늘 배운 단어·문장 저장 (기억용 그림/사진 포함)
- 아침·저녁: 스펠링, 받아쓰기, 듣고 뜻+불어 쓰기, 읽고 말하기 테스트
- 오답노트: 틀린 것만 모아서 복습
- 관리자 페이지(`#admin`): 할 일, 일기, 공부 기록, 통계

데이터는 각자 브라우저(localStorage)에만 저장돼요. 이 저장소에는 개인 기록이 올라가지 않아요.
